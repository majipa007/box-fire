# 18: Graphics and crosshair settings

**What to build:** The menu gains a render scale setting, a shadows toggle, crosshair colour and size, and a low-end preset.

**Blocked by:** 08

- [x] Crosshair colour and size can be changed.
- [x] The low-end preset sets 50 % render scale with shadows off.
