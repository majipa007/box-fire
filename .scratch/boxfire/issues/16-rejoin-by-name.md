# 16: Rejoin by name

**What to build:** If your tab dies, reopen the URL with the same name and your kills come back.

**Blocked by:** 15

**Status:** ready-for-agent

- [ ] After 30 s with nobody connected, the game returns to the lobby with scores cleared.
